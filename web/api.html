开发者 API

MacNas 对外开放一组 HTTP 接口：用一把 API Key，就能在自己的脚本或应用里 列目录、下载、搜索、上传、新建、改名、移动、删除。 接口是 JSON、带权限范围、按 key 限流，/api/v1 的字段只增不改。

HTTP + JSON Bearer API Key 只读 / 读写权限 按 key 限流 v1 稳定
看快速上手 完整文档（Markdown）

基础地址就是你 Mac 的局域网地址，例如 http://192.168.1.20:7654

01

快速上手

三步：拿 key、调通第一个接口、开始批量处理。

1

在软件里生成一把 API Key

MacNas →「设置」→「开发者 API」→ 填名字、勾权限（只读 / 读写）、可选有效期 →「生成」。 明文 key 只显示一次，请立刻保存。撤销也在这个页面，撤销后立即失效。

2

调通第一个接口

export MACNAS="http://192.168.1.20:7654"
export KEY="macnas_你保存下来的那一串"

curl -s -H "Authorization: Bearer $KEY" "$MACNAS/api/v1/me"
{
  "ok": true,
  "apiVersion": "v1",
  "caller": "我的备份脚本",
  "scopes": ["read", "write"],
  "volumeCount": 1
}
3

拿到目录 id，开始干活

curl -s -H "Authorization: Bearer $KEY" "$MACNAS/api/v1/volumes"
# → volumes[].id 就是后面所有接口要带的 volume 参数
02

读接口（只读权限即可）

列目录、下载、搜索、缩略图、预览。

列目录

curl -s -H "Authorization: Bearer $KEY" \
  "$MACNAS/api/v1/files?volume=$VOL&path=/照片"

返回 folders 与 files 两组，每个文件都带 id、 path、size、sha256、createdAt。

下载

curl -H "Authorization: Bearer $KEY" -o 海边.jpg \
  "$MACNAS/api/v1/files/download?volume=$VOL&id=$ID"

支持 Range，可以断点续传；也可以直接用 path= 代替 id=。

搜索

curl -s -H "Authorization: Bearer $KEY" \
  "$MACNAS/api/v1/search?q=海边"

不传 volume 就搜所有目录，最多返回 200 条。

缩略图 / 预览

curl -H "Authorization: Bearer $KEY" -o t.jpg \
  "$MACNAS/api/v1/thumbnails?volume=$VOL&id=$ID&size=256"

缩略图是 JPEG；/api/v1/preview 给出该怎么渲染， /preview/content 直接给内容（图片原图、文本、Word 转好的 HTML、其它格式的渲染图）。

03

写接口（需要读写权限）

上传、新建文件夹、重命名、移动/复制、删除。

上传（请求体就是文件本身，不是 multipart）

curl -H "Authorization: Bearer $KEY" -X POST \
  --data-binary @本地文件.jpg \
  "$MACNAS/api/v1/files/upload?volume=$VOL&path=/照片&name=新照片.jpg"

同名默认自动改名（新照片 (2).jpg），要覆盖就加 &overwrite=1。 内容在库里已存在时返回 outcome: "deduplicated" —— 记录建好了，但一个字节都没多占。

新建文件夹 / 重命名 / 移动 / 删除

# 新建
curl -s -H "Authorization: Bearer $KEY" -X POST -H 'Content-Type: application/json' \
  -d '{"volume":"'$VOL'","path":"/","name":"归档"}' \
  "$MACNAS/api/v1/folders"

# 重命名
curl -s -H "Authorization: Bearer $KEY" -X POST -H 'Content-Type: application/json' \
  -d '{"volume":"'$VOL'","id":"'$ID'","name":"改名后.jpg"}' \
  "$MACNAS/api/v1/files/rename"

# 移动（mode 也可以填 copy）
curl -s -H "Authorization: Bearer $KEY" -X POST -H 'Content-Type: application/json' \
  -d '{"volume":"'$VOL'","ids":["'$ID'"],"toPath":"/归档","mode":"move"}' \
  "$MACNAS/api/v1/files/move"

# 删除（进回收站，用户还能还原）
curl -s -H "Authorization: Bearer $KEY" -X DELETE \
  "$MACNAS/api/v1/files?volume=$VOL&id=$ID"

删除是进回收站，不是永久删除 —— 和你手动点「移到回收站」完全一样。

04

错误与限流

所有错误形状一致，方便你统一处理。

{ "error": { "code": "read_only_key",
             "message": "这个 API Key 只有只读权限，写操作被拒绝。" } }
HTTPcode含义
400missing_volume, bad_name, missing_target, missing_query, empty_body参数不全或名字不合法
401unauthorized, invalid_key没带凭据 / key 不存在（多为没复制完整）
403key_disabled, key_expired, read_only_keykey 被撤销、已过期，或用只读 key 调了写接口
404not_found, unknown_volume文件或目录不存在
405method_not_allowed方法用错了
429rate_limited请求太频繁，响应头带 Retry-After（秒）

限流

每把 key 单独计算：读 600 次/分钟、写 120 次/分钟。 批量同步建议加并发上限，并遵守 Retry-After。

跨域（CORS）

默认完全不开：key 落到浏览器页面里，等于把钥匙交给那个网页。 确实需要时，在「设置 → 开发者 API → 允许跨域来源」里填白名单。

05

接口清单

前缀统一是 /api/v1。

方法路径权限说明
GET/me任意key 信息与权限
GET/volumes只读列出存储目录
GET/stats只读空间统计（可带 volume）
GET/files只读列目录
GET/files/stat只读单个文件元信息
GET/files/download只读下载（支持 Range）
GET/search只读搜索
GET/thumbnails只读缩略图
GET/preview · /preview/content只读预览
POST/files/upload读写上传
POST/folders读写新建文件夹
POST/files/rename读写重命名
POST/files/move读写移动 / 复制
DELETE/files · POST /files/delete读写删除（进回收站）

有意不开放的能力：改账号密码端口、创建/撤销分享链接、清空回收站与彻底删除、 移除存储目录与重建索引 —— 这些只能在本机软件里做，避免第三方误操作把系统搞乱。 需要的话到 GitHub issue 说明场景，我们评估在 v2 里加。
